# Определение матрицы

Матрица — это прямоугольная таблица элементов, организованных в строки и столбцы, для которых определены правила математических действий.
Матрица представляет собой массив элементов, которые могут быть числами, функциями, символами или другими объектами, при условии, что для них заданы определённые операции сложения и умножения (или другие алгебраические действия).  
Количество строк и столбцов задаёт размер матрицы, обычно обозначаемый как m×n, где   
m — число строк, а n — число столбцов. 
Элементы матрицы обозначаются a_ij, где 
i — номер строки, а 
j — номер столбца.
