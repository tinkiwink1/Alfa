# Alfa
Вариант №5. Алгебра  

**Требования:**  

1. Презентация должна быть выполнена с помощью Markdown, где это возможно
2. Презентация должна быть выполнена с помощью фреймворка Reveal.JS
3. Тема(оформление) обязательно должна быть вынесена в отдельный CSS файл
4. Минимальное количество слайдов: 20
5. Перед каждым разделом необходимо использовать слайд-разделитель
6. Оформление презентации должно быть читаемым (например, черно-синий текст на черном фоне не допускаются)
7. Обязательными являются титульный слайд, заключительный слайд
8. Обязательно наличие меню для быстрого перехода к слайду, используя плагин reveal.js-menu. Меню должно быть рабочим. Все слайды должны иметь наименование в меню
9. Обязательно наличие навигации: стрелки, номер слайда
10. Обязательно наличие readme в корне презентации с заданием без указания баллов
11. В случае сомнения самостоятельности выполнения работы - требуется обоснования спорных мест
12. На слайде не должно быть скроллов
13. Минимальное количество изображений в презентации - 3
14. После создания репозитория - запрещается его удалять и перезаливать презентацию в новый репозиторий. Если есть проблемы - обращайтесь за помощью.
15. Необходимо использовать локальную версию фреймворка Reveal.js
16. Максимальная дата сдачи презентации 1 июня 2026 года.
  
**Система штрафов**  

1. Перезаливка презентации в новый репозиторий после начала сдачи работы - 30 баллов  
2. Использование облачных библиотек и фреймворков - 30 баллов
3. Использование облачных библиотек и фреймворков - 30 баллов
4. Сдача работы 2 июня и позднее - 30 баллов
5. Обязательные слайды
6. Определение матрицы - 1 балл
7. Виды матриц с примерами - 7 баллов
8. Сумма матриц (алгоритм и пример) - 8 баллов
9. Умножение матриц (алгоритм и пример) - 8 баллов
10. Определитель матрицы (определение и алгоритмы нахождения) - 8 баллов
11. Программы, написанные на языке JavaScript для нахождения суммы и произведения матриц. Запрещается использования библиотеки mathjs и ей подобных - 36 баллов (14 баллов за сложение и 22 балла за умножение )
12. Программы, написанные на языке JavaScript для нахождения определителя квадратной матрицы 2,3,4 порядка - 18 баллов (2, 5, 11 баллов соответственно)
13. Исходный код программ - 2 балла
14. При наличии оставшихся слайдов, но не менее 3, заполнить веселыми картинками по теме - 2 балла
